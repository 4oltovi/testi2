## Формулаи Баҳои Ниҳоӣ

```
БА КМ: Ниҳоӣ = R1×0.15 + R2×0.15 + КМ×0.30 + Имтиҳон×0.40
БЕ КМ: Ниҳоӣ = R1×0.30 + R2×0.30 + Имтиҳон×0.40

GPA = Σ(Gi × Ci) / Σ(Ci)
  Ку: Gi = grade point, Ci = кредитҳо
```
